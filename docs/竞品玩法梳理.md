# 竞品玩法梳理：Neopets / Adopt Me! / 模拟人生 4 猫狗

> 用途：做 WarmPet 玩法与美术决策时的参照。
> 说明：三款都**不是微信小游戏**，没有 4MB 主包和 20MB 总量的限制，
> 也都不靠广告变现。**思路可参考，规格和商业模型不能照抄。**
> 事实来源：维基百科、官方页面、Cocos/EA 官方文章；引用处已标注可信度。

---

## 一、Neopets（尼奥宠物）

| | |
| --- | --- |
| 上线 | 1999 年 11 月 15 日，跑了 26 年 |
| 平台 | 网页（Flash → HTML5） |
| 创办 | Adam Powell、Donna Williams；几经易主（Viacom → JumpStart → NetDragon） |
| 定位 | 虚拟宠物 + 虚拟世界（Neopia） |

### 核心循环

```
玩小游戏赚 Neopoints → 买食物道具 → 喂养照顾宠物
        ↓                              ↓
   收集 / 交易 / 炒股              喷漆换色 / 穿戴打扮
        ↓                              ↓
   Battledome 对战 ←──── 训练宠物 ────┘
```

**没有固定目标**（官方原话 "There is no set objective"）。玩家自己找乐子：
收集、打扮、对战、社交、囤货炒股都行。这是它能活二十六年的根本原因——
玩法是一张网而不是一条线，某个模块玩腻了还有别的。

### 关键机制

| 机制 | 做法 |
| --- | --- |
| 照顾 | 宠物会饿会生病，需要喂食吃药 |
| **惩罚** | **宠物不会死**，但健康低会限制能玩的内容 |
| 赚钱 | 大量小游戏，分数换点数，**每天最多提交三次成绩**（防刷） |
| 定制 | 物种 + 颜色（笔刷/变形药水/实验室射线）+ 穿戴服饰 |
| 套娃 | Petpet——你的宠物也能有自己的宠物 |
| 战斗 | Battledome，PvP 和 PvE 都有 |
| 经济 | 玩家间买卖交易、拍卖、**股票市场** |
| 社交 | 论坛、公会 |

### 变现

双货币：**Neopoints**（游戏内免费赚）+ **Neocash**（真钱充值）。
**穿戴物品有相当一部分只能用 Neocash 买。**

> ⚠️ 这条对我们很关键：Neopets 被称道的换装深度，
> 商业上是架在付费货币之上的。**我们铁律不接支付，这个模型对不上。**
> 能借鉴的是它的数据结构和惩罚设计，不是它的变现方式。

## 二、Adopt Me!（Roblox）

| | |
| --- | --- |
| 上线 | 2017 年 7 月 14 日 |
| 平台 | Roblox（不是独立 App，是平台内的一个"体验"） |
| 开发 | Uplift Games（原 DreamCraft），约 40 人 |
| 规模 | 累计访问 **445 亿次**；历史最高同时在线 **192 万**；2026 年 8 月实时在线 22–30 万 |
| 收入 | 年约 **6000 万美元**，主要来自微交易 |

### 核心循环

```
买蛋 → 做任务孵化 → 幼年宠物
                        ↓
        喂食 / 洗澡 / 玩耍 / 睡觉 → 赚 Bucks + 成长到成年
                        ↓
        4 只成年同种 → Neon（霓虹）
                        ↓
        4 只 Neon → Mega Neon（闪亮彩虹）
                        ↓
                 玩家间交易 → 稀有度即身份
```

### 关键机制

| 机制 | 做法 |
| --- | --- |
| 获取 | 孵蛋，每种蛋有固定概率池，稀有度五档（普通→传奇） |
| **概率时点** | **稀有度在买蛋那一刻就定了**，跟你孵得快不快无关 |
| 照顾 | 喂食/洗澡/玩耍/睡觉，既是养成也是赚币手段 |
| 成长 | 新生 → 幼年 → 成年，多阶段 |
| **深度** | **融合**：4 成年 → 霓虹，4 霓虹 → 超级霓虹（需 16 只） |
| 稀缺 | 限时活动宠物停产后成硬通货（暗影龙、霜龙、蝙蝠龙） |
| 经济 | **玩家间自由交易**，这是整个游戏的发动机 |
| 其他 | 家园装饰、载具、角色扮演、连续登录奖励 |

### 争议

目标用户是低龄儿童 + 重度微交易，出现过澳洲小孩花掉 8000 澳元的事件。

> 我们铁律不接支付，某种程度上正是规避这类风险。
> 但也要认清：**它的发动机是微交易 + 玩家交易，这两样我们都没有。**
> 把稀有度体系搬过来会得到一个空壳——玩家抽到传奇宠物，不能卖、不能换、
> 稀缺性没有出口，追逐动力撑不起来。

## 三、模拟人生 4：猫狗（The Sims 4: Cats & Dogs）

| | |
| --- | --- |
| 上线 | 2017 年 11 月 10 日（第 4 个资料片），2018 年 7 月出主机版 |
| 平台 | PC / Mac / 主机 |
| 开发 | Maxis / EA |
| 定位 | 人生模拟游戏的宠物资料片，不是独立宠物游戏 |

### 核心循环

```
Create a Pet 捏宠 → 领养 → 与宠物互动建立羁绊
                              ↓
        观察行为判断需求 → 喂食 / 玩耍 / 训练技巧 / 遛狗
                              ↓
              生病 → 送兽医诊所 → 治疗
                              ↓
        配种繁殖 → 幼崽遗传特征 → 回到捏宠
```

### 关键机制

| 机制 | 做法 |
| --- | --- |
| 捏宠 | 123 狗品种 + 49 猫品种，可混血、调体型、笔刷画毛色、穿衣服、选声音 |
| **不可控** | **宠物不能被玩家直接操控**，也没有作弊码可以解锁 |
| **不显示需求** | **UI 里不显示宠物的需求条**，只能观察行为和情绪状态去猜 |
| 性格 | 特质系统，影响行为；玩家要摸索宠物的恐惧和渴望 |
| **惩罚** | 除了老死不会死，但**长期疏于照顾会被动物管理局带走** |
| 训练 | 教狗做一连串越来越复杂的技巧 |
| 经营 | **兽医诊所**：自建、雇员工、定价、诊断治疗、有星级评分 |
| 繁殖 | 配种、怀孕、产崽、遗传 |

### 两个反直觉的设计

**不可操控 + 不显示需求条**，是刻意为之：它要的是"这是一只有自己脾气的动物"，
不是"一个待办清单"。玩家得靠观察去揣摩，这种不确定性正是养宠物的真实感来源。

代价是**上手门槛高、反馈慢**。有玩家抱怨"宠物在我不理它的时候就呆坐着"。
这个取舍在 PC 买断制游戏里成立（玩家愿意投入时间），
**在碎片化的小游戏里大概率不成立**。

## 四、横向对比

| | Neopets | Adopt Me! | 模拟人生 4 猫狗 |
| --- | --- | --- | --- |
| 核心驱动 | 收集 + 打扮 + 社交 | **收集 + 交易 + 攀比** | **独一无二 + 陪伴感** |
| 玩家关系 | 我的收藏品 | 我的资产 | 我的家人 |
| 获取方式 | 领养 / 喷漆 | **抽蛋（概率）** | **捏（完全自定义）** |
| 成长深度 | 等级 + 战斗 | **融合形态（16 只换 1 只）** | 繁殖遗传 |
| 属性可见 | 可见 | 可见 | **不可见，靠观察** |
| 死亡惩罚 | 不会死，健康低限制玩法 | 无 | 不会死，但会被带走 |
| 变现 | 付费货币买穿戴 | 微交易 + 交易经济 | 买断 + 资料片 |
| 社交 | 论坛、公会、交易、拍卖 | **玩家间自由交易** | 无（单机） |

### 三条共识

跨越二十六年、三个平台、三种商业模式，这三款都做了同一件事：

1. **宠物不会死。** 惩罚只是限制玩法或触发事件，永远不可逆地失去宠物。
   这跟 WarmPet 铁律「软失败不死亡」完全一致，是被长期验证过的养成品类共识。
2. **日常照顾是货币来源。** 喂食洗澡不只是养成动作，同时产出资源，
   给「每天回来」一个功利理由。WarmPet 的互动产出游戏币是同一套逻辑。
3. **外观是长线消费点。** 三款的深度都压在"让宠物变得不一样"上，
   而不是压在数值成长上。

## 五、对 WarmPet 的映射

### 已经有的（接口层已支持）

| 能力 | 对应接口 | 对标 |
| --- | --- | --- |
| 日常照顾产出货币 | `/pet/feed` `/bath` `/pet` `/play` | 三款共有 |
| 属性衰减 + 不死 | 惰性结算 + 软失败铁律 | Neopets / 模拟人生 |
| 抽取收集 | `/gacha`（含概率公示） | Adopt Me |
| 收集进度 | `/dex` 图鉴 | Neopets |
| 外观换装 | `/wardrobe` 四槽位 | 三款共有 |
| 家园装饰 | `/home` 6×6 网格 | Adopt Me |
| 轻竞技 | `/race` 赛跑 | Neopets Battledome |
| 离线收益 | `/pet/offline` | 放置类通用 |

**结论：WarmPet 的玩法骨架其实相当完整**，横向对比下来该有的模块基本都有。
缺的不是系统，是内容量和表现力。

### 明确没有、且不该有的

| 缺失 | 原因 |
| --- | --- |
| 玩家间交易 | 接口层没有；且交易 + 稀有度容易触碰合规红线 |
| 付费货币 | **铁律：全程不接入支付** |
| 稀有度攀比 | 没有交易和支付作出口，稀缺性无处兑现 |

**所以 Adopt Me 那套"稀有度驱动"我们学不了**，
不是技术做不到，是缺少让稀缺性产生价值的经济出口。

### 值得考虑引入的

1. **成长阶段的视觉变化**（对标 Adopt Me 的新生→幼年→成年）。
   接口里已经有 `stage` 字段（`baby` / `teen` / `adult`），**目前前端没用**。
   同一个模型缩放 + 换比例就能表达，成本极低，但"看着它长大"的感知很强。
2. **连续登录奖励**。已有 `/daily` 签到与连签递增，方向一致。
3. **宠物的宠物 / 摆件互动**（对标 Petpet）。家园系统已有家具，
   可以让宠物与家具产生互动动画，成本比新增系统低得多。

### 明确不建议抄的

- **模拟人生的"不显示需求条"**：那是 PC 买断制的取舍，
  碎片化小游戏里会直接劝退。WarmPet 现在四条属性条直白可见，是对的。
- **Neopets 的"每天限交三次成绩"**：那是 2000 年代防刷手段，
  我们服务端权威 + 每日上限已经解决了同样的问题。
